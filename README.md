# Rama Studio — Landing Page

Página de vendas do curso **Babyliss Duradouro** do Rama Studio.
Site estático (HTML/CSS/JS), sem dependências ou build.

## Estrutura
- `index.html` — conteúdo e seções da página
- `style.css` — estilos e identidade visual (Bodoni Moda + DM Sans, paleta Rama Studio)
- `script.js` — contagem regressiva da oferta

## Como visualizar
Abra o `index.html` no navegador (duplo clique).

## Personalizar antes de publicar
No `index.html`, procure e substitua:
- `[[LINK_CHECKOUT]]` — link de pagamento (Hotmart/Kiwify/Eduzz/Stripe)
- `[[PRECO]]` — valor do curso

Para o vídeo de apresentação, veja as instruções no bloco `.video-frame` do `index.html`.
